Design notes — why this looks the way it does
  • Hero replaces five flat KPI cards. The previous Total / Allocated / Expected / Actual / Variance strip showed five overlapping numbers with no relationship between them. The multi-marker bar carries all five values in one visual, and the narrative sentence does the interpretation the user used to do in their head.
  • No "Unallocated" tile. It's derivable as Total − Allocated. The striped trailing segment in the progress bar communicates the buffer at a glance; the save-row footer states the exact dollars. One tile less means the hero stays the visual focal point.
  • "Allocated" folded into the bar. The dark non-actual segment shows allocated-but-not-yet-spent capacity; the lime-yellow ceiling tick shows where allocation ends. No need for a separate Allocated KPI.
  • Current month gets a primary-color left accent. In the live view, "where are we right now" was a scan-the-table guess. The Current pill + accent border + warmer row tint make it unambiguous, and the row stays editable even while live data updates inside it.
  • Past-month spotlight pulls one closed period forward. Borrowed from 028-reports-v2/budget-mock.html. Most users open this page asking "what happened last month?" — answering that above the table beats forcing them to find and expand the April row.
  • Anthropic running rows keep their cyan signal, dialed down. The current implementation uses a stronger blue background; here it's a subtle tinted row plus a cyan "live" chip. Same semantics, less visual noise — and workspace breakdown indents under the parent row exactly like the live code already does.
