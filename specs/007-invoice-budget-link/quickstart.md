# Quickstart: Invoice–Budget Integration

**Feature**: 007-invoice-budget-link
**Date**: 2026-03-05

---

## Prerequisites

- Node.js LTS, pnpm installed
- Neon PostgreSQL database URL in `.env.local`
- Cloudflare R2 credentials in `.env.local`
- Anthropic API key in `.env.local`
- Run `pnpm install` after adding `unzipper`

## Setup Steps

### 1. Install new dependency

```bash
pnpm add unzipper
pnpm add -D @types/unzipper
```

### 2. Apply database migration

```bash
pnpm db:generate   # generates 0004_invoice_budget_link.sql
pnpm db:migrate    # applies to Neon DB
```

### 3. Start dev server

```bash
pnpm dev
```

---

## Testing the Feature

### Single invoice auto-link

1. Log in as admin → navigate to **Invoices → Upload Invoice**
2. Upload a PDF invoice dated within an existing budget period
3. Confirm extracted fields (vendor auto-filled if detected)
4. Click **Save to Archive**
5. Expected: success toast includes the period label (e.g. "Linked to Mar 2025")
6. Navigate to **Budget → [year] → [March period]** — invoice amount appears in billed costs

### Vendor field

1. Upload a PDF that clearly shows a company name
2. The vendor input should be pre-filled with amber border if low-confidence, or white border if medium/high
3. Edit the vendor name → save — confirm the corrected value appears in the invoice list

### No-match notice

1. Upload an invoice dated outside all active budget periods (e.g. year 2020)
2. Save — expect a warning toast: "No active budget period covers this invoice date"
3. Invoice appears in the archive without a linked period

### Batch zip upload

1. Navigate to **Invoices → Bulk Upload**
2. Zip 3 PDF invoices and upload the zip
3. Batch review table appears with extracted fields; one row per PDF
4. Correct any fields → click **Save All**
5. Summary shows per-file outcome (saved / linked / failed)
