Current-day cost estimate — UI mockup

How the clearly-labelled estimated today figure appears on the Claude dashboard. The estimate is always a dashed / ghosted, "est." chipped treatment — visually distinct from solid actuals — and is never merged into the actual month-to-date total. Three views: the KPI strip, the daily cost chart, and the cumulative pacing chart, plus the 1st-of-month before/after that motivates the change.

Pattern reused: the same ghost/dashed treatment as the existing "projected" bar in twelve-month-bar-chart.tsx (fillOpacity 0.22, strokeDasharray "4 3"). The estimate is a single trailing bar at "today"; every prior bar is a solid billed actual. Tomorrow the dashed bar becomes a solid billed bar automatically.

Pattern reused: cumulative-pacing-chart.tsx already draws a dashed projection line and a "today" reference line. The only change: the projection anchor moves from "last complete day" to today, using MTD + est. today — so the line crosses the budget ceiling at the right date instead of lagging a day behind.
